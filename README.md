# AI API Integration Project

## Overview
This project demonstrates integration with multiple AI providers:
- OpenAI
- Groq
- Ollama
- Hugging Face
- Google Gemini
- Cohere

## Setup

1. Clone the repo
2. Install dependencies:
   pip install -r requirements.txt

3. Create a .env file and add API keys

## Run Example

python openai_api.py

## Features
- User input prompt
- API request handling
- Error handling
- Secure API key usage
